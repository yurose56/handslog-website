# 핸즈로그(Handslog) 공식 홈페이지

사업자의 입장에서 생각하는 온라인 마케팅 파트너, 핸즈로그의 공식 홈페이지입니다.
빌드 도구 없이 순수 HTML / CSS / JavaScript로 제작되었습니다 (즉시 브라우저에서 열람 가능).

**v3 업데이트 (포지셔닝 전면 개편):** "학원 전문 마케팅 회사"로 보일 수 있던 인상을 걷어내고,
"사업의 강점을 먼저 찾아 필요한 마케팅을 함께 실행하는 파트너"로 포지셔닝을 명확히 했습니다.
주요 변경 사항:
- HERO/문제 제기/서비스/프로세스/FAQ 등 전 섹션 카피를 대표의 13년 자영업 경험과
  "사업 본질이 먼저, 마케팅은 그것을 전달하는 역할" 철학 중심으로 다시 작성
- PHILOSOPHY 섹션을 신설해 "마케팅보다 먼저 사업의 본질을 봅니다" 메시지를 별도로 강조하고,
  기존 선언문 섹션은 PRINCIPLES(하지 않는 것)로 분리
- 서비스에 "추가 온라인 마케팅" 항목을 추가하고 브랜드 블로그의 작업 흐름을 명시
- 이든영어수학학원 사례는 "핸즈로그의 정체성이 아닌 하나의 실제 운영 사례"로 명확히 하고,
  확인되지 않은 등록 성과는 쓰지 않음 (검색 노출·문의 건수 등 확인된 사실만 기재)
- FAQ를 9개 문항으로 확장 (지역/업종 무관, 브랜드 블로그 단독 진행, 플레이스 병행 등)
- SEO(title/description/OG)를 "온라인 마케팅" 중심 키워드로 재작성, 학원 키워드는 사례 문맥에만 유지

구조(파일 구성, id, 클래스 체계)는 기존 v2와 대부분 동일하게 유지했고, 반응형 브레이크포인트도 그대로입니다.
(과거 v2 변경 이력: 카드 박스 반복형 레이아웃을 섹션별로 다른 표현 방식으로 재구성하고 포인트 컬러를 조정)

## 실행 방법

별도 설치 없이 `index.html`을 브라우저로 열면 됩니다.
로컬 서버로 확인하려면 예: `npx serve .` 또는 VS Code Live Server 확장을 사용하세요.

## 폴더 구조

```
handslog-website/
├── index.html              # 원페이지 랜딩 (전체 섹션 포함)
├── assets/
│   ├── css/style.css       # 전체 스타일 (색상/여백 변수는 :root에서 관리)
│   ├── js/main.js          # 모바일 메뉴 토글 등 인터랙션
│   └── images/             # 실제 사용 이미지 + 미사용 원본
│       └── _originals/     # 리사이즈 전 원본 백업 (용량이 크므로 배포 시 제외 권장)
└── README.md
```

## 실제 오픈 전 반드시 채워야 할 항목 (TODO)

v2부터는 화면(방문자 눈에 보이는 곳)에 "TODO" 문구를 노출하지 않습니다.
대신 채워야 할 항목을 아래 표와, `index.html` 안의 `<!-- TODO(dev): ... -->` HTML 주석에만 남겨두었습니다.
`Ctrl+F`로 `TODO(dev)`를 검색하면 코드 상의 위치를 모두 찾을 수 있습니다.

| 위치 | 항목 | 파일 |
|---|---|---|
| Final CTA 섹션 | 네이버 톡톡 / 카카오채널 / 전화 / 이메일 실제 링크·번호 | `index.html` `#contact` (HTML 주석 참고) |
| Final CTA 섹션 | "핸즈로그에 상담 문의하기" 버튼 — 채널이 정해지면 `href`를 연결하고 `contact-cta-disabled` 클래스 제거 | `index.html` |
| 푸터 | 대표자명 / 사업자등록번호 / 사업장 주소 / 전화 / 이메일 — 화면에는 아직 노출하지 않음 | `index.html` `<footer>` 위 HTML 주석 참고 |
| `<head>` | 실제 도메인 확정 후 `canonical`, `og:url` 태그 추가 | `index.html` |
| 사례(Case Study) | 네이버 톡톡 문의 실제 화면 — 아직 해당 캡처가 없어 자리표시자로 남아 있음 | `index.html` `#case` (`.img-frame`, 가운데 슬롯) |
| 상담 신청 폼 | 현재 미포함 — 폼 데이터를 받을 방식(이메일 연동 서비스 등)이 정해지면 별도로 추가 | - |

> 참고: 국내에서 상거래·광고성 웹사이트를 운영할 경우 통상 푸터에 상호·대표자·사업자등록번호·주소 등을
> 표기합니다. 실제 정보가 확정되면 위 표의 푸터 항목에 반영해주세요.

## 색상 팔레트 (제안, 확정 아님)

지정된 브랜드 컬러가 없어 아래 값으로 임시 제안했습니다 (v2: 기존 브라운 톤을 더 세련된 톤으로 조정).
`assets/css/style.css` 최상단 `:root` 변수만 바꾸면 전체 사이트에 반영됩니다.

- 기본 배경 (warm white / ivory): `#FBF9F4`
- 보조 배경 (soft beige): `#F2E9DC`
- 기본 텍스트 (deep navy-charcoal): `#20263A`
- 포인트 (muted terracotta / warm copper, CTA·강조 전용): `#BD6B44`

## 향후 확장 (`/cases`, `/blog`)

현재는 원페이지 랜딩이지만, 헤더/푸터 마크업과 CSS 클래스 체계를 그대로 재사용해
`/cases/index.html`, `/blog/index.html` 형태의 정적 페이지로 확장할 수 있도록 구조화했습니다.
페이지 수가 늘어나면 헤더·푸터 중복 관리를 줄이기 위해 정적 사이트 생성기(Astro 등) 전환을 검토하는 것을 권장합니다.

## 콘텐츠 수정 방법

모든 텍스트는 `index.html`에 시맨틱 HTML로 직접 작성되어 있어, 별도 빌드 과정 없이
해당 텍스트를 바로 수정하면 됩니다 (서비스 설명, FAQ 답변, 가격 안내 문구 등).
